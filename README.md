# SystemMonitor

## Setup (kjør én gang på hver maskin)

```bash
python -m venv .venv
.venv\Scripts\pip.exe install -r requirements.txt
```

## Kjør appen

```bash
.venv\Scripts\python.exe __main__.py
```

Eller bruk `run.bat` for enkel oppstart.

## VS Code debugging

1. Åpne mappen i VS Code
2. Trykk F5 for å starte med debugging
3. Første gang opprettes .venv og avhengigheter installeres automatisk
